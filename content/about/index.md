지노소프트 기술 블로그는 **Jinosoft(지노소프트)**가 운영하는 개인 기술 블로그다. 개발 도구를 설치하고, 서비스를 구성하고, 제품을 만드는 과정에서 확인한 내용을 기록한다.

## 다루는 내용

- WSL, Docker, Android Studio 등 개발 환경 설치와 구성
- Kafka 등 백엔드 기술의 동작 원리와 실행 예제
- 클라우드 인프라 구성과 비용 비교
- GitHub 활용, 오픈소스 라이선스, 개발 중 확인한 문제와 해결 방법

## 글을 작성하는 방식

직접 실행한 내용은 명령어, 설정 파일, 캡처 화면과 함께 정리한다. 공식 문서에서 확인한 동작과 직접 확인한 결과를 구분하고, 비용 비교에는 기준일과 계산 조건을 적는다. 예시 금액이나 권장 구성은 모든 환경에 동일하게 적용되는 정답이 아니라, 자신의 환경에 맞춰 검토할 출발점으로 제시한다.

글의 오류나 변경된 내용을 발견했다면 관련 글 주소와 확인한 내용을 [문의 페이지](/contact/)의 이메일로 알려 주세요.
