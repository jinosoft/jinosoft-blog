서버를 직접 구매해 IDC에 둘까, 월 요금을 내고 물리 서버를 빌릴까, 클라우드 가상서버를 사용할까? 서버 한 대를 운영하더라도 장비 구매비, 회선 요금, 디스크와 트래픽이 청구되는 방식은 다르다.

비용을 비교할 때는 월 요금뿐 아니라 **장비 구매비와 사용 기간 동안의 총액**을 함께 봐야 한다. 물리 서버 한 대를 여러 VM으로 나눠 쓸 수 있다면, 클라우드에서 VM을 각각 임대하는 경우와 비용 구조도 달라진다. 공개 상품의 월 기본요금과 5년 합계, VM 2–3개 운영 예시를 통해 선택 기준을 살펴본다.

## 서버 구매·서버호스팅·클라우드는 무엇이 다를까

{{< table-scroll label="서버 구매와 코로케이션, 물리 서버 임대, 클라우드 VM의 차이" >}}
| 구성 | 사용하는 자원 | 기본 비용 구조 | 직접 관리할 부분 |
| --- | --- | --- | --- |
| A. 서버 구매 + IDC 이용 | 구매한 물리 서버를 IDC에 설치. 코로케이션 또는 구매형 서버호스팅 이용 | 장비 구매비 + 월 상면·전력·회선 요금 | OS·프로그램·백업, 장비 고장 시 교체와 지원 계약 |
| B. 물리 서버 임대 | 사업자가 제공하는 물리 서버 한 대 | 서버와 IDC 이용이 포함된 월 요금 | OS·프로그램·백업. 하드웨어 지원 범위는 계약 확인 |
| C. 월정액 가상서버(VPS) | 물리 서버 위에서 실행되는 VM | VM·디스크·트래픽을 묶은 월정액 | OS·프로그램·백업, 포함량과 초과 사용 관리 |
| 자원별 과금 퍼블릭 클라우드 | 선택한 리전의 VM·디스크와 부가 서비스 | VM·디스크·IP·전송량 등 자원별 요금 | OS·프로그램·백업, 자원 및 과금 설정 |
{{< /table-scroll >}}

**‘서버호스팅’이라는 상품명만으로 물리 서버 임대인지 판단하면 안 된다.** 구매형 서버호스팅과 가상서버 호스팅도 같은 이름을 사용한다. 물리 서버인지 VM인지, 장비 구매비가 있는지, 월 요금에 어떤 자원이 포함되는지 확인한다.

C의 비용 예시는 클라우드 기반 월정액 VPS 상품이다. 자원을 나누어 과금하는 퍼블릭 클라우드의 비용 항목과 이그레스는 뒤에서 별도로 계산한다.

## 서버 한 대, 월 비용과 5년 비용 예시

아래는 **2026년 10월 12일 확인한 공개 상품 요금**을 이용한 계산이다. A/B/C는 운영 방식의 예시 이름이며, 실제 업체 링크와 선택한 상품은 글 아래 출처에 정리했다.

각 구성은 사양과 서버 위치가 다른 상품이다. 범위는 선정 상품의 가격이며 동일 성능 견적이나 시장 전체 가격대가 아니다. 비용표 아래의 사양·네트워크 조건을 함께 확인한다.

- 물리 서버 한 대 또는 VM 한 대를 Linux 서버로 5년, 즉 60개월 유지한다.
- 선택한 상품의 기본 디스크·네트워크 조건 안에서 사용하고, 기간 중 사양과 요금이 유지된다고 가정한다.
- 금액은 부가세 제외로 맞춘다. VAT 포함 월정액은 1.1로 나누어 계산했다.
- 백업 저장소, 운영 인건비, 상용 소프트웨어, 별도 설치·관리비와 초과 사용료는 합계에 포함하지 않았다.

{{< table-scroll label="서버 한 대의 장비 구매비와 월 요금, 5년 기본요금 예시" >}}
| 구성 | 장비 구매비 | 월 기본요금 | 장비비 포함 5년 기본비용 |
| --- | ---: | ---: | ---: |
| A. 서버 구매 + IDC 이용 | 약 135만–190만 원 | 89,100–90,000원 | 6,696,000–7,300,000원 |
| B. 물리 서버 임대 | 없음 | 90,000–110,000원 | 5,400,000–6,600,000원 |
| C. 클라우드 기반 VM 월정액 | 없음 | 60,000–120,000원 | 3,600,000–7,200,000원 |
{{< /table-scroll >}}

합계 계산은 단순하다.

```text
A 하한: 1,350,000원 + 89,100원 × 60개월 = 6,696,000원
A 상한: 1,900,000원 + 90,000원 × 60개월 = 7,300,000원
B·C: 월 기본요금 × 60개월
```

A는 선택한 구매형 상품·1대 상면 요금의 양 끝값으로 계산했다. B는 물리 서버 임대 상품 두 개, C는 VM 월정액 상품 두 개의 범위다. **각 범위는 선택한 상품들의 예시이며, 시장 전체의 최저가나 최대 비용은 아니다.**

C의 게시 요금은 VAT 포함 월 66,000–132,000원이며, 표에서는 VAT 제외 월 60,000–120,000원으로 환산했다.

### 같은 가격표에서 사양과 네트워크도 확인하기

| 구성 | 선택한 상품의 사양 | 네트워크·위치 조건 |
| --- | --- | --- |
| A. 서버 구매 + IDC 이용 | 물리 CPU 4코어, 메모리 8GB, SATA HDD 1TB | 선택한 구매형 상품 또는 1대 상면 이용료. 회선의 공유 여부와 보장 대역폭은 공급사별 확인 |
| B. 물리 서버 임대 | 물리 CPU 4코어, 메모리 16–32GB, SSD 250GB + SATA 1TB | 상품 표기상 10Mbps Bandwidth, 1Gbps Line |
| C. 클라우드 기반 VM 월정액 | 가상 CPU 2–4코어, 메모리 4–8GB, 디스크 80–160GB | 월 트래픽 4–5TB 포함. 공식 상품 안내상 서버 위치는 일본 |

물리 CPU와 가상 CPU는 코어 수만으로 처리 성능이 같다고 볼 수 없다. CPU 세대, 메모리 용량, HDD·SSD 구성도 다르므로 위 표는 같은 성능의 견적 비교가 아니다. 필요한 자원을 골랐을 때 비용이 어떻게 쌓이는지 보는 예시다.

A의 공개 장비 목록에는 오래된 CPU 세대가 포함되어 있다. 실제 구입 시에는 현재 판매 여부와 보증 조건부터 확인해야 한다. A의 5년 합계는 기간 중 장비 교체가 없다는 가정이며, 5년 사용 가능성이나 무고장을 보장하는 금액이 아니다. 장비의 잔존 가치와 부품 교체비는 TCO에서 따로 반영한다.

B의 1Gbps 회선 표기와 10Mbps 대역폭 표기는 구분해야 한다. 회선 연결 속도만 보고 기본요금에 1Gbps 사용량이 포함된 것으로 계산하면 안 된다. C는 월 누적 트래픽 기준이며, 기준을 넘으면 초과 사용료가 추가된다.

서버 위치도 비용만큼 중요하다. C의 예시 상품은 일본에 있으므로 국내 데이터 보관이나 국내 서버 위치가 요구되는 서비스라면 다른 지역의 상품으로 견적을 다시 받아야 한다. 실제 지연 시간은 이용자 위치와 네트워크 경로를 고려해 확인한다.

## 물리 서버 한 대에서 VM 2–3개를 운영한다면

구성 A와 B의 물리 서버에 Proxmox VE나 KVM 같은 하이퍼바이저를 설치하면 CPU·메모리·디스크를 나눠 여러 VM을 운영할 수 있다. 공급사의 하이퍼바이저 설치 허용 여부, OS 재설치 방법과 CPU 가상화 기능부터 확인한다. [Proxmox VE 하드웨어 요구사항](https://www.proxmox.com/en/products/proxmox-virtual-environment/requirements)은 가상화 기능과 호스트·게스트에 필요한 메모리를 별도로 안내한다.

예를 들어 B의 월 11만 원 상품은 물리 CPU 4코어, 메모리 32GB, SSD 250GB와 SATA 1TB를 제공한다. 여기에 **각각 2vCPU·메모리 4GB·디스크 80GB인 VM을 2–3개** 배치하는 자원 배분을 검토할 수 있다. 아래는 실제 구축·성능 검증 결과가 아닌 배분과 요금 계산 예시다.

VM 3개에 메모리 12GB를 배정하면 나머지는 호스트와 캐시 등에 사용할 수 있다. 디스크는 VM 합계 240GB 외에 호스트 OS 공간도 필요하므로 SSD·HDD 배치를 함께 계획한다. 총 6vCPU는 물리 4코어를 공유한다. 모든 VM이 CPU를 계속 많이 사용하는 서비스라면 이 사양에서 원하는 처리량을 낼 수 있는지 테스트해야 한다.

VM 디스크를 모두 SSD에 배치할 수 있다고 가정하지는 않는다. 포맷 후 사용 가능 용량과 GB·GiB 차이, 호스트·스냅샷 공간을 확인하고, HDD에 배치하는 VM의 I/O 성능은 별도로 검증한다.

비교 대상은 C의 2vCPU·4GB·80GB VM 상품이며, VM 한 개당 VAT 제외 월 6만 원이다. 포함된 네트워크 조건과 서버 위치는 앞의 사양표와 같고, 가상화 운영비·추가 IP·트래픽 초과료는 아래 기본요금에 포함하지 않았다.

B의 계약 대역폭 10Mbps는 호스트 내 모든 VM이 공유하고, C는 VM마다 월 트래픽 4TB가 제공된다. 아래 표는 VM 수에 따른 기본요금 차이를 보여주며, 처리 성능·저장소·네트워크·장애 범위가 같다는 뜻은 아니다.

{{< table-scroll label="VM 2–3개 기본요금 예시: 성능과 저장소, 네트워크, 장애 범위는 다름" >}}
| 비용 항목 | VM 2개 운영 | VM 3개 운영 |
| --- | ---: | ---: |
| 물리 호스트 한 대의 월 기본요금 | 110,000원 | 110,000원 |
| 클라우드 VM의 월 기본요금 합계 | 60,000원 × 2 = 120,000원 | 60,000원 × 3 = 180,000원 |
| 물리 호스트 한 대의 5년 기본요금 | 6,600,000원 | 6,600,000원 |
| 클라우드 VM의 5년 기본요금 합계 | 7,200,000원 | 10,800,000원 |
| 5년 기본요금 차액(클라우드 VM − 물리 호스트) | 600,000원 | 4,200,000원 |
{{< /table-scroll >}}

**물리 서버의 자원 안에서 여러 VM을 운영할 수 있다면, VM 수가 늘어날수록 클라우드 VM의 기본요금 합계와 차이가 벌어질 수 있다.** 이 예시의 차이는 VM 2개에서 월 1만 원, 3개에서 월 7만 원이다. 추가 운영·백업·IP 비용과 필요한 디스크 구성을 반영한 뒤 비용 이점을 판단한다. 2개 예시의 5년 차액은 60만 원이므로, 가상화 운영의 추가 비용이 이보다 크면 기본요금상의 이점은 사라진다.

앞의 A 예시 장비는 메모리가 8GB다. 4GB VM을 2–3개 운영하려면 호스트 메모리까지 고려해 증설이나 상위 모델 구입비를 다시 계산해야 한다. VM 수만 늘리고 같은 장비 구매비를 그대로 적용할 수는 없다.

VM마다 공인 IP가 필요하면 추가 IP 요금과 공급사의 네트워크 정책을 확인한다. 하나의 공인 IP를 공유하는 경우에는 NAT·포트 전달 또는 웹 서비스용 리버스 프록시 등의 구성이 필요하다. 물리 호스트가 고장 나거나 재부팅되면 그 안의 VM도 모두 영향을 받는다. 웹·DB를 VM으로 분리하더라도 같은 물리 호스트에 있으면 호스트 장애에 대한 이중화가 되지 않는다.

## 퍼블릭 클라우드는 어떤 비용을 더해야 할까

C는 VM·디스크·일정량의 트래픽이 포함된 월정액 가상서버 상품이다. Google Cloud Compute Engine처럼 자원을 나누어 과금하는 상품은 다음 항목을 합산한다.

```text
월 예상 비용 = VM + 디스크 + 공인 IP + 외부로 보내는 데이터
             + 백업 + 추가로 사용하는 DB·로드 밸런서 등
```

이 방식에서는 리전, VM 사양, 디스크 종류·용량, 공인 IP 개수, 송신 데이터량을 먼저 정한다. 월 사용 시간은 **730시간을 비교 가정**으로 사용하고, 5년에는 `730시간 × 60개월 = 43,800시간`을 적용한다. 실제 청구는 해당 상품의 사용 시간과 요금 정책에 따른다. 할인 약정이나 무료 크레딧을 적용한다면 적용 전·후 금액을 구분한다.

예를 들어 [Google Cloud 가격 계산기](https://cloud.google.com/products/calculator?hl=ko)에 서울 리전(`asia-northeast3`), VM 한 대, 월 730시간, 필요한 디스크와 IP, 송신량을 넣고 전체 금액을 산출한다. 원화로 비교할 때는 적용 환율과 VAT 기준도 함께 적는다.

VM을 늘려 여러 존에 배치하거나 관리형 DB를 추가하면 단일 서버 예시보다 비용이 늘어난다. 한 대의 VM을 생성한 것만으로 애플리케이션과 DB의 장애 복구 구성이 완성되는 것도 아니므로, 복구 목표에 필요한 자원을 별도로 포함한다.

## 이그레스가 많으면 네트워크 비용부터 계산하기

이그레스(egress)는 서버에서 외부로 나가는 데이터다. 사용자가 사진·동영상·설치 파일을 다운로드하거나 API 응답을 받을 때도 데이터가 외부로 전송된다. 이미지·동영상이나 대용량 파일을 제공할 서비스라면 VM 가격과 함께 **월 송신량과 초과 전송 단가**를 먼저 확인해야 한다.

### 월정액 VM의 포함량과 초과 요금

C의 월 6만 원 VM에는 월 트래픽 4TB가 포함된다. [공식 트래픽 안내](https://help.cafe24.com/faq/server-hosting/easyup-server-hosting/service-inquiry/easyup-server-hosting-traffic-guide/)의 초과 요금은 VAT 포함 GB당 110원, VAT 제외 GB당 100원이다. 공급사의 월 트래픽 계량값이 포함량을 넘었다고 가정하면 다음처럼 계산한다.

{{< table-scroll label="월정액 VM의 트래픽 초과분을 포함한 월 요금과 5년 비용" >}}
| 공급사 계량 기준 초과분 | 월 추가 전송료 | VM 기본요금 포함 월 합계 | 같은 사용량의 5년 합계 |
| --- | ---: | ---: | ---: |
| 포함량 이내 | 0원 | 60,000원 | 3,600,000원 |
| 포함량 초과 1,000GB | 100,000원 | 160,000원 | 9,600,000원 |
| 포함량 초과 5,000GB | 500,000원 | 560,000원 | 33,600,000원 |
{{< /table-scroll >}}

금액은 VAT 제외이며, 60개월 동안 같은 요금과 초과량이 유지된다는 가정이다. VM을 여러 개 쓰는 경우 포함량을 서로 합산해 공유할 수 있는지도 계약에서 확인한다.

공급사의 FAQ는 `1TB = 1,024GB`로 계산 예시를 작성하지만 수신·송신 중 무엇을 합산하는지는 해당 안내에서 명확히 확인되지 않는다. 실제 계량 단위와 집계 범위를 확인해야 하므로 C의 포함 트래픽을 GCP 인터넷 송신량과 동일한 조건으로 직접 비교하지 않는다.

### GCP 서울 리전에서 한국으로 전송하는 예시

[Google Cloud 네트워크 가격표](https://cloud.google.com/vpc/network-pricing?hl=ko)의 출발 리전을 서울(`asia-northeast3`)로 선택하고, **한국 목적지·Premium Tier 인터넷 송신**을 기준으로 계산한다. 이 블로그의 [서울 리전 공식 가격표 캡처](/posts/gcp-cloud-vpn-selection-guide/gcp-seoul-korea-egress-pricing.png)에 표시된 구간은 월 0–10,240GiB에 `$0.19/GiB`, 10,240GiB를 넘는 부분에 `$0.15/GiB`다.

아래는 해당 송신 SKU에 집계되는 월 사용량을 가정한 **네트워크 요금만의 계산**이다. `1TiB = 1,024GiB`이며, 원화는 현재 환율이 아닌 **$1 = 1,400원 가정**, VAT 제외다. VM·디스크·IP·CDN·로드 밸런서 등의 요금은 포함하지 않았다. 원화는 USD 요금의 비교용 환산값이며 원화 결제 계정의 실제 청구액은 해당 통화의 SKU 가격을 확인한다.

{{< table-scroll label="GCP 서울에서 한국으로 보내는 Premium Tier 데이터의 월 전송료와 5년 비용" >}}
| 월 송신량 | 월 전송료(USD) | 월 원화 환산 | 같은 사용량의 5년 전송료 |
| --- | ---: | ---: | ---: |
| 100GiB | $19.00 | 26,600원 | 1,596,000원 |
| 500GiB | $95.00 | 133,000원 | 7,980,000원 |
| 1TiB(1,024GiB) | $194.56 | 272,384원 | 16,343,040원 |
{{< /table-scroll >}}

표의 송신량은 모두 첫 요금 구간에 해당하므로 월 송신량에 $0.19/GiB를 곱했다. 5년 열은 매월 같은 전송량·단가·환율이 유지된다는 가정으로 월 원화 환산액에 60을 곱했다. 원문 가격표에서 출발 리전과 목적지를 바꾸면 단가도 달라지므로 실제 서비스 조건으로 다시 산출한다.

**월정액 VM의 기본 포함량 안에서 쓰는 경우와, GCP처럼 전송량에 따라 청구되는 경우는 비용 구조가 크게 다르다.** 위 GCP 전송료를 C의 기본요금에 그대로 더하는 계산은 하지 않는다. 각각의 공급사 요금 정책으로 VM과 전송료를 합산해야 한다.

물리 서버 임대와 코로케이션도 네트워크가 무제한으로 포함되는 것은 아니다. 계약 대역폭, 트래픽 측정 방식, 추가 회선과 초과 요금을 확인한다. 큰 파일을 자주 제공한다면 필요한 피크 대역폭까지 견적에 넣는다. CDN을 이용할 계획이면 CDN 전송료와 원본 데이터 접근 비용도 함께 계산한다.

## 5년 TCO에 추가할 비용

TCO(Total Cost of Ownership, 총소유비용)는 장비비와 기본 사용료에 운영·유지·교체 비용 등을 더한 값이다. 앞의 표는 공개 요금으로 계산할 수 있는 기본비용이며, 실제 5년 TCO는 다음 항목을 포함한다.

```text
5년 TCO = 장비 구매비 + 60개월 기본 사용료
        + 설치·자원 증설·부품 교체·유지보수
        + 가상화 및 OS·프로그램 운영 인건비·라이선스
        + 백업·복구·추가 IP·트래픽 초과 비용
        - 5년 후 장비 처분액
```

구매형은 보증 종료 후 교체와 수리비를, 물리 서버에서 여러 VM을 운영한다면 하이퍼바이저 관리와 VM별 백업·복구 비용을 반영한다. 임대와 클라우드도 OS·프로그램 운영, 백업, 초과 사용료가 남는다. 장비 처분액은 소유 장비를 처분하는 경우에만 반영한다.

운영 인건비는 `예상 작업 시간 × 시간당 비용`으로 산출하고, 백업·라이선스·추가 회선은 실제 견적을 넣는다. 확인되지 않은 항목은 별도 산정 대상으로 남겨둔다. 이중화가 필요해 물리 호스트를 추가한다면 구매비와 월 요금도 추가해 다시 비교한다.

## 어떤 조건에서 무엇을 선택할까

{{< table-scroll label="서버 구매와 임대, 클라우드 선택 기준" >}}
| 필요한 조건 | 먼저 검토할 방식 | 견적에서 확인할 것 |
| --- | --- | --- |
| 이미 서버가 있고 장비·OS를 직접 운영할 수 있음 | 코로케이션 | 장비 입고 규격, 전력·회선, 원격 작업, 부품 교체 지원 |

| 여러 VM을 한 호스트에 배치하고 자원·가상화 관리를 직접 할 수 있음 | 서버 구매·물리 서버 임대 후 가상화 | 총 CPU 부하, 호스트 메모리, 디스크 성능, 추가 IP, 호스트 장애 시 복구 |

| 사진·동영상·대용량 파일 등 외부 전송량이 많음 | 포함 트래픽이 있는 상품·회선 계약과 퍼블릭 클라우드를 함께 견적 | 월 송신량, 피크 대역폭, 초과 단가, CDN을 포함한 전체 전송비 |
| 특정 리전, 여러 존, 관리형 DB, 자동 확장이 필요함 | 퍼블릭 클라우드 | 요구 구성 전체의 VM·DB·네트워크·백업 비용 |
{{< /table-scroll >}}

먼저 VM 개수와 필요한 자원, 서버 위치, 월 송신량·피크 대역폭, 허용 중단 시간과 복구 목표를 정한다. 이 조건으로 각 방식의 견적을 받고, 기본비용에 운영·백업·교체 비용을 더해 5년 예산을 비교한다. 물리 서버의 회선 견적에도 같은 송신량과 피크 대역폭을 전달해야 한다.

## 예시 가격의 출처와 적용 범위

가격은 확인 시점의 공개 표시값이며 실제 견적·재고·약정에 따라 달라질 수 있다. 아래에는 각 예시의 계산 근거를 확인할 수 있도록 공식 페이지를 연결했다.

- 구성 A의 하한: [두드림 서버 구매 가격표](https://nic.co.kr/server/server_buy.php)의 4코어·8GB·SATA 1TB 상품 중 135만 원 모델과 [코로케이션 요금표](https://nic.co.kr/server/colocation.php)의 1U 월 89,100원. VAT 별도이며 코로케이션은 2년 약정이다. 장비 입고와 서비스 결합 조건은 계약 전에 확인한다.
- 구성 A의 상한: [아이네임즈 IDC 요금 안내](https://idc.inames.co.kr/)의 ASUS R300 E7 상품에 게시된 서버 비용 190만 원과 월 이용료 9만 원. [구매 신청 페이지](https://idc.inames.co.kr/idcOrders?group_no=1)는 VAT 별도를 안내한다. 장비 소유권과 현재 제공 사양은 계약에서 확인한다.
- 구성 B: [카페24 퀵서버호스팅](https://hosting.cafe24.com/?controller=new_product_page&page=quick)의 Quick 라이트업 Pro와 Quick 스타트업 Pro. 게시된 월 요금은 9만–11만 원(VAT 별도)이며 설치비는 무료다.
- 구성 C: [카페24 이지업 서버호스팅](https://hosting.cafe24.com/?controller=new_product_page&page=easyupB)의 EASY B와 EASY C. 게시된 월 요금은 66,000–132,000원(VAT 포함)이며 상품 FAQ에서 일본 서버 위치를 안내한다. [트래픽 안내](https://help.cafe24.com/faq/server-hosting/easyup-server-hosting/service-inquiry/easyup-server-hosting-traffic-guide/)에서 포함량과 초과 요금, 사양 변경 조건을 확인할 수 있다.
- 다른 물리 서버 견적을 받을 때 참고할 자료: [후이즈 IDC 서버호스팅](https://idc.whois.co.kr/?act=server.content&tpl=serverhosting). 상품 사양과 포함 지원이 달라 위 예시 합계에 섞지 않았다.
- 자원별 클라우드 요금 확인: [Google Cloud Compute Engine 가격 안내](https://cloud.google.com/products/compute/pricing?hl=ko), [가격 계산기](https://cloud.google.com/products/calculator?hl=ko), [네트워크 가격표](https://cloud.google.com/vpc/network-pricing?hl=ko).
